# Mango Moon — CSC 436 Project

## Description
A single‑page restaurant website built for CSC 436 demonstrating semantic HTML, responsive CSS, Flexbox, Grid layout, and a JavaScript dark/light mode toggle.

## Live Site
(Added after Netlify deployment)

## GitHub Repository
https://github.com/FantasyGodX/436_Proj1

## Features
- Semantic HTML structure
- Flexbox header layout
- CSS Grid menu layout
- Responsive design with media queries
- Dark/Light mode toggle using JavaScript
- Anchor‑based navigation (Home, Menu, Order)
- Styled order form

## Technologies Used
- HTML5  
- CSS3 (Flexbox, Grid, Media Queries)  
- JavaScript (DOM manipulation)  
- Git & GitHub  
- Netlify

## How to Run
1. Clone the repository:  
   `git clone https://github.com/FantasyGodX/436_Proj1.git`
2. Open the folder.
3. Open `index.html` in any browser.
